The agent's system prompt

This is the real string agent/prompt.py hands the model every turn. Edits are saved to agent/prompt_override.txt — never to the Python file — so a bad edit can't break the agent, and deleting the override restores the shipped prompt exactly.

Placeholders {ds_name} {baseline} {target} {suffix} {data_rel} are filled per dataset. Any other literal brace must be doubled.
