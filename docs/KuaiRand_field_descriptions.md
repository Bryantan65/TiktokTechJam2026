# KuaiRand Dataset Field Descriptions

Source: https://kuairand.com/

---

## 1. Interaction Logs (`log_xxx.csv`)

| Field Name | Description | Type | Example |
|---|---|---|---|
| user_id | The ID of the user. | int64 | 17387 |
| video_id | The ID of the video. | int64 | 1123453 |
| date | The date of this interaction. | int64 | 20220421 |
| hourmin | The time of this interaction (HHMM format). | int64 | 400 |
| time_ms | The timestamp of this interaction in milliseconds. | int64 | 1650485801301 |
| is_click | A binary feedback signal. In dual-column UI: indicates a click. In single-column UI: means "valid_play" — `play_time_ms >= duration_ms` if `duration_ms <= 7000`, or `play_time_ms > 7000` if `duration_ms > 7000`. | int64 | 1 |
| is_like | A binary feedback signal indicating the user hit the "like" button. | int64 | 0 |
| is_follow | A binary feedback signal indicating the user followed the author. | int64 | 0 |
| is_comment | A binary feedback signal indicating the user wrote a comment. | int64 | 0 |
| is_forward | A binary feedback signal indicating the user forwarded this video. | int64 | 0 |
| is_hate | A binary feedback signal indicating the user hated this video. | int64 | 0 |
| long_view | A binary signal equal to 1 when `play_time_ms >= duration_ms` if `duration_ms <= 18000`, or `play_time_ms >= 18000` if `duration_ms > 18000`. | int64 | 1 |
| play_time_ms | The user's view time in milliseconds. | int64 | 151024 |
| duration_ms | The video's duration time in milliseconds. | int64 | 104400 |
| profile_stay_time | Time spent on the author's profile page (in milliseconds). | int64 | 0 |
| comment_stay_time | Time spent in the comments section (in milliseconds). | int64 | 0 |
| is_profile_enter | A binary signal indicating whether the user entered the author's profile. | int64 | 0 |
| is_rand | A binary signal indicating if this video is generated by the random intervention. | int64 | 0 |
| tab | Scenario of this interaction, e.g., in the recommendation page or the main page (range 0-14). | int64 | 1 |
